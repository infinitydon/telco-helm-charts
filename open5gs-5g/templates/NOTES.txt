Open5GS 5G SA lab installed.

{{- if .Values.webui.enabled }}
Open the WebUI:
{{- if eq .Values.webui.service.type "NodePort" }}
  NodePort: {{ .Values.webui.service.nodePort }}
  Browse to http://<worker-node-ip>:{{ .Values.webui.service.nodePort }} and log in with admin / 1423.
{{- else }}
  kubectl port-forward service/{{ include "open5gs-5g.fullname" . }}-webui 9999:{{ .Values.webui.service.port }}
  Browse to http://localhost:9999 and log in with admin / 1423.
{{- end }}
{{- end }}

{{- if .Values.phoneUi.enabled }}
Open the UE phone browser:
{{- if eq .Values.phoneUi.service.type "NodePort" }}
  Browse to https://<worker-node-ip>:{{ .Values.phoneUi.service.nodePort }}
{{- else }}
  kubectl port-forward service/{{ include "open5gs-5g.fullname" . }}-phone 5800:{{ .Values.phoneUi.service.port }}
  Browse to http://localhost:5800
{{- end }}
{{- end }}

Multus networks:
  N2: {{ include "open5gs-5g.fullname" . }}-n2
  N3: {{ include "open5gs-5g.fullname" . }}-n3
  N4: {{ include "open5gs-5g.fullname" . }}-n4
  N6: {{ include "open5gs-5g.fullname" . }}-n6

Check registration and the PDU session:
  kubectl logs deploy/{{ include "open5gs-5g.fullname" . }}-ue

Ping the N6 test endpoint through the UE tunnel:
  kubectl exec deploy/{{ include "open5gs-5g.fullname" . }}-ue -- ping -I uesimtun0 {{ .Values.addresses.dataN6 }}

{{- if .Values.phoneUi.enabled }}
Verify phone traffic exits through the UE tunnel:
  kubectl exec deploy/{{ include "open5gs-5g.fullname" . }}-ue -c phone-proxy -- verify-ue-path
{{- end }}

{{- if .Values.librespeed.enabled }}
Run the browser-based speed test over the 5G user plane:
  Open http://{{ .Values.addresses.librespeedN6 }}:{{ .Values.librespeed.port }} inside the UE phone or redroid browser.
  LibreSpeed telemetry and public-IP lookup are disabled.
{{- end }}

{{- if .Values.redroid.enabled }}
Connect to the redroid Android UE:
{{- if eq .Values.redroid.service.type "NodePort" }}
  adb connect <worker-node-ip>:{{ .Values.redroid.service.nodePort }}
  scrcpy -s <worker-node-ip>:{{ .Values.redroid.service.nodePort }}
{{- else }}
  kubectl port-forward service/{{ include "open5gs-5g.fullname" . }}-redroid-adb 5555:{{ .Values.redroid.service.port }}
  adb connect localhost:5555
  scrcpy -s localhost:5555
{{- end }}
{{- end }}
